# 목표와 계획

이 저장소의 목표·범위·완료 기준과 큰 단계를 적는다. 실행할 개별 작업과 차례는 [TASKS.md](../TASKS.md), 지금 상태는 [STATE.md](../STATE.md), 완료·취소 이력은 [LANDED.md](../LANDED.md)에 기록한다.

## 배경

Claude Code와 Codex는 플러그인을 받는 마켓플레이스 형식이 다르다. 한 저장소에서 두 형식을 함께 관리해, 같은 플러그인을 두 도구에서 같은 버전으로 받게 한다.

## 목표

| 목표 | 달성 여부를 확인할 기준 |
|---|---|
| 공개 플러그인을 Claude Code와 Codex에서 함께 받게 한다 | `claude plugin validate .`가 오류 없이 끝나고, 두 마켓플레이스와 `README.md` 목록에 같은 플러그인이 있다 |
| 두 도구에서 같은 버전을 받게 한다 | 플러그인마다 두 `plugin.json`의 `version`이 같다 |

## 범위

- 다룰 것: `plugins/` 아래 플러그인, 두 마켓플레이스 파일, 플러그인별 설치·사용 안내
- 다루지 않을 것: 개인용 플러그인과 공통 스킬 원본(다른 저장소에서 관리한다)

## 단계

| 단계 | 결과물 | 완료 기준 |
|---|---|---|
| `codyssey-final-check` 저장소 점검 | `all`, `G1`~`G7` 입력 | 플러그인 README '사용법' 표에서 '사용 가능' |
| `codyssey-final-check` 서비스 검증 | `서비스 검증` 입력 | 플러그인 README '사용법' 표에서 '준비 중'이 '사용 가능'으로 바뀐다 |

## 정할 것

| 질문 | 결정에 필요한 근거 |
|---|---|
| 공개 저장소의 라이선스 | 플러그인을 남이 고쳐 다시 배포해도 되는지에 대한 사용자 결정 |
